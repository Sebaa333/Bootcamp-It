# Bootcamp-It

Este repositorio lo creé para centralizar todos los ejercicios del bootcamp en un solo lugar, en vez de andar creando un repo nuevo por cada práctica o ejercicio.

## ¿Por qué?

- Menos ruido en mi perfil de GitHub.
- Todo el progreso del bootcamp queda ordenado y fácil de encontrar.
- Puedo comparar cómo fui evolucionando entre un ejercicio y otro.

## Estructura

Cada carpeta es un ejercicio o práctico independiente:

- `Sebastian_Santivanez_practico-1/`
- `Sebastian_Santivanez_practico-2/`
- `Sebastian_Santivanez_practico-3/`
- `practico05/`
- `Ejercicio-n4/`
- `Ejercicio 7 - Ejecicios JS lógica/`
- `Integradores/`
- `colaboradores/`
